# wtm — initial build

**Date:** 2026-10-06

## Goal

A simple terminal UI, **Worktree Manager (wtm)**, written in Go with Bubble Tea
and Lip Gloss. It lists the git worktrees in the current directory and lets the
user create, delete, rename and prune them. It takes over the whole terminal
(alternate screen, no scrollback).

## Decisions made with the user

| Question | Decision |
|----------|----------|
| The spec said both "C" and "A" open the create popover | **C**, to match the legend |
| Where new worktrees go | Inside the current directory (`./<name>`). The expected layout is a container folder holding a bare repo in `.bare/` and a `.git` file containing `gitdir: ./.bare` |
| Deleting with uncommitted changes or unmerged commits | **Fail safely** and show git's error. Never force |

## Environment and dependencies

- Go wasn't installed. I installed it with Homebrew (Go 1.27.1).
- The current major versions of the Charm libraries are used:
  - `charm.land/bubbletea/v2` v2.0.10
  - `charm.land/bubbles/v2` v2.2.1 (text inputs)
  - `charm.land/lipgloss/v2` v2.0.6 (styling and compositing the popovers)
- The Go module is named `wtm`.

## Features

- **List:** shows every worktree from `git worktree list --porcelain` with its
  name (path relative to the current directory), branch, short commit hash,
  and tags: `bare`, `main`, `locked`, `prunable`. ↑/↓ or j/k moves the
  selection, and g/G jump to the top or bottom. The list scrolls when it doesn't
  fit, with a position indicator.
- **Menu below the list:** C Create, D Delete, R Rename, P Prune, Q Quit.
  Upper- or lower-case keys both work.
- **Create (C):** a popover with a *Name* field and a *Base branch* field
  (default `main`). Tab switches fields, Enter submits and Esc cancels. Runs
  `git worktree add -b <name> ./<name> <base>`.
- **Delete (D):** a confirmation dialog showing the directory and branch. On
  `y`/Enter it runs `git worktree remove` and then `git branch -d`.
- **Rename (R):** a popover pre-filled with the current name. Runs
  `git worktree move` and then `git branch -m`, so the directory and branch are
  renamed together.
- **Prune (P):** runs `git worktree prune --verbose` and reports how many stale
  entries it removed.
- **Errors:** every failure opens an error dialog. Git failures show the
  command and git's own output. An empty name is reported inside the popover
  without running git.
- **Status line:** shows progress and the result of the last action. After
  create and rename, the selection moves to the new worktree.

## Safety behaviour

- The first worktree (the bare repo or main checkout) can't be deleted or
  renamed. Trying it shows an explanation in the error dialog.
- **Names** are checked with `git check-ref-format --branch`. Names starting
  with `-` and `@{-N}`-style shorthands are rejected.
- **Delete** first checks that the branch is merged into its upstream, or into
  `HEAD` if it has none, the same rule `git branch -d` uses. That way it fails
  *before* removing anything. `git worktree remove` without `--force` refuses
  dirty or untracked worktrees.
- **Rename** checks for an existing branch or directory with the new name
  before changing anything. If a later step still fails, the message says
  which part was already done.
- **Folders:** names containing `/` create nested folders. Empty parent folders
  are removed after a delete or rename, but never above the current directory.
- **Escape:** Esc closes dialogs but doesn't quit the app. Only Q and ctrl+c quit.

## Code layout

| File | Purpose |
|------|---------|
| `main.go` | Entry point. Checks git is installed, resolves the working directory and starts the program |
| `git.go` | `Git` type wrapping the git CLI: `List`, `Create`, `Delete`, `Rename`, `Prune`, porcelain parsing, name checks, and `GitError` |
| `model.go` | Bubble Tea model: modes (list, create, delete, rename, error), key handling, and git operations run in the background |
| `view.go` | Rendering: main screen, popovers composited over a dimmed copy of the list, and path shortening (`./name`, `~`) |
| `git_test.go` | Integration tests against real temporary repos in the container layout |
| `model_test.go` | UI tests driven by key presses: full create → rename → delete flow, error dialogs, prune, scrolling, and checks that every screen fits the terminal |
| `README.md` | Usage, keys and build instructions |

## Verification

- `go vet ./...` is clean and `go test ./...` passes.
- I ran the real binary in tmux at 90×26 and 60×16 and exercised create,
  rename, delete (including the error for a dirty worktree), prune, the error
  for acting on the bare repo, and quit.

## Issues found and fixed during the build

- **Popover positioning:** composing Lip Gloss layers directly onto a canvas
  ignores their X/Y position, so the popover replaced the screen. Fixed by
  wrapping the layers in a `lipgloss.NewCompositor`.
- **Deleting a stale worktree:** the first version ran a full
  `git worktree prune`, which also cleared other stale entries.
  `git worktree remove` already handles a missing folder, so it's used for all
  deletes.
- **Unmerged branches:** the first version removed the worktree and then failed
  on `git branch -d`. The merge check now happens up front.
- **Popover wording:** I made the delete and rename text clearer and shortened
  long paths in the popovers. Git is now given `./name` paths, so its error
  messages are shorter too.

## Known limitations and possible follow-ups

- Prune doesn't delete the branches of pruned worktrees, which matches git's
  own behaviour.
- Rename doesn't rename git's internal record of the worktree
  (`.bare/worktrees/<old-name>`). Nobody sees this name, and git works fine.
- If the base branch only exists on the remote (e.g. `origin/main` with no
  local `main`), the user has to type `origin/main`. There is no automatic
  fallback.
- Ideas for later: force-delete after a safe delete fails, a refresh key, and a
  fetch before create.
